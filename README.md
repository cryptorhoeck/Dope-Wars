# Dope Wars: Moncton

Buy low, sell high, don't get caught. A Moncton-flavoured Dope Wars with three
modes: Classic, Career, and Mafia.

- Play: https://dopewarsmoncton.tail8174d5.ts.net/play/
- Android APK: https://dopewarsmoncton.tail8174d5.ts.net/downloads/latest.apk
- What's new: `CHANGELOG.md`

Everything is one file, `index.html`, plus a bundled copy of Tone.js and two
fonts. No build step. The version is `GAME_VERSION` near the top of the script.
